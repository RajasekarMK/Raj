# FreshCut – Meat Shop UI

A clean, responsive storefront UI for selling chicken, mutton, fish and eggs. Built with plain HTML, CSS and JavaScript; there is no build step.

**Run it:** open `index.html` in a browser, or serve the folder with `npx serve .`

## Features
- Category tabs (Chicken, Mutton, Fish, Eggs, Marinated), search and sorting
- Product cards with weight options (500 g / 1 kg), MRP vs. offer price and badges
- Add/remove quantity stepper, slide-in cart drawer, free-delivery progress hint
- Mobile layout with a two-column grid and a sticky bottom "View cart" bar
- Cart saved in `localStorage`

Product data lives in the `PRODUCTS` array at the top of `app.js`.
